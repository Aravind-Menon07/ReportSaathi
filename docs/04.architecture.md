## 1. Executive Summary & Architecture Principles

**ReportSaathi** is designed as an ephemeral, patient-centric health literacy tool that converts printed medical laboratory reports and printed prescriptions into plain-language explanations in **English**, **Hindi**, and **Kannada**.

### Core Engineering Principles
1. **Zero-Retention Ephemeral Pipeline:** No Protected Health Information (PHI) or Personally Identifiable Information (PII) is persisted to disk or databases beyond the active HTTP request/session lifecycle, fully adhering to the Indian **Digital Personal Data Protection (DPDP) Act, 2023**.
2. **Deterministic Range Evaluation Before AI Inference:** The system separates numeric lab evaluation from linguistic simplification. Reference ranges are evaluated **deterministically** via regex and numeric interval comparisons strictly against the numbers printed on the user's specific document—preventing LLM hallucination of clinical reference ranges.
3. **Mandatory Human-in-the-Loop (HITL) Verification:** OCR-extracted text and numeric values must be presented alongside the original document image in a side-by-side verification screen so the user can verify and edit extracted numbers before they are sent to the AI explanation layer.
4. **Hard-Coded Clinical Safety Guardrails:** System prompts and deterministic post-processors enforce zero-tolerance rules against clinical diagnosis, treatment recommendations, drug schedule modifications, and doctor substitution.

## 3. Component Specifications

### 3.1 DPDP-Aligned Consent & Ephemeral Pre-Processing
* **Consent Gate:** Users must explicitly acknowledge the notice of data processing before file selection, detailing the exact purpose (educational explanation), zero-retention policy, and absence of medical advice.
* **Input Validation:**
  * Supported Formats: `application/pdf`, `image/jpeg`, `image/png`, `image/jpg`.
  * Maximum File Size: `10 MB`.
  * Rate-Limiting: Ephemeral IP-based token bucket (via in-memory Redis/Cache on Render, 10 requests / 15 minutes).
* **PII Redaction Engine:**
  * Regex filters immediately scrub detected Indian phone numbers (`+91`, 10-digit formats), Aadhaar masks (`\d{4}\s\d{4}\s\d{4}`), email addresses, and patient names from the extracted text payload before sending to the LLM.

### 3.2 Human-in-the-Loop OCR Engine
* **Pre-processing (OpenCV):**
  * Auto-rotation and deskewing via Hough line transforms.
  * Adaptive thresholding (Otsu's binarization) to enhance contrast on photographed crumpled paper slips.
  * Noise reduction (Gaussian Blur / Bilateral Filtering) for low-light camera captures.
* **Extraction (Tesseract OCR 5.x):**
  * Page Segmentation Mode (`--psm 6` for uniform tables, `--psm 4` for column structures).
  * Generates structured bounding boxes `(x, y, w, h)`, confidence scores, and line-level text.
* **Side-by-Side Review Interface:**
  * Renders original document image on the left with interactive highlighted bounding boxes.
  * Displays parsed table on the right with editable fields:
    * `Test / Medication Name`
    * `Observed Value`
    * `Unit of Measurement`
    * `Printed Reference Range`
  * The user must click **"Confirm & Explain"** to submit the verified JSON payload.

### 3.3 Deterministic Reference Range Engine
To guarantee zero hallucinations of medical metrics:
* The system executes a deterministic parser over the printed reference range string:
  * Range patterns: `min - max`, `< max`, `> min`, `<= max`, `>= min`.
  * Example: `Observed: 14.2`, `Range: 11.5 - 16.0` $\rightarrow$ `NORMAL`.
  * Example: `Observed: 6.8`, `Range: 4.0 - 5.6` $\rightarrow$ `HIGH`.
  * Example: `Range missing or illegible` $\rightarrow$ Status set to `RANGE_NOT_PROVIDED`.
* **Zero Invention Rule:** If the uploaded report does not contain a printed reference range, the status is flagged as `Indeterminate / Ask Your Doctor`. The system strictly prohibits querying external reference tables or LLM knowledge for ranges.

### 3.4 AI Explanation & Prompt Orchestration
* **Model:** Google Gemini API (`gemini-2.0-flash` or `gemini-1.5-flash`).
* **Settings:** `temperature: 0.2`, `top_p: 0.9`, `response_format: {"type": "json_object"}`.
* **Prompt Schema Enforcer:**

```json
{
  "tests": [
    {
      "name": "Hemoglobin",
      "observed_value": "9.2",
      "unit": "g/dL",
      "reference_range": "12.0 - 15.0",
      "status": "LOW",
      "plain_explanation": "Hemoglobin is the protein in red blood cells that carries oxygen from your lungs throughout your body. Your value is below the normal range printed on this report.",
      "simple_meaning": "Low oxygen-carrying capacity in the blood."
    }
  ],
  "doctor_questions": [
    "What might be causing my hemoglobin level to be lower than the normal range?",
    "Do I need any dietary changes or iron supplements based on this result?",
    "When should I repeat this test to check if my level has improved?"
  ],
  "safety_disclaimer": "This explanation is educational and not a medical diagnosis. Please discuss these results with your healthcare provider."
}
```

* **Reading Depth Selector:**
  * **Simple:** Single-sentence everyday analogy (Grade 5 reading level).
  * **Standard (Default):** Two-to-three sentence clear explanation with biological function.
  * **Detailed:** Includes physiological context and common clinical reasons for deviation, strictly without naming specific personal diagnoses.

* **Multilingual Rendering:**
  * Full support for **English**, **Hindi (हिन्दी)**, and **Kannada (ಕನ್ನಡ)**.
  * UTF-8 script integrity validation in API serialization and PDF export.

### 3.5 Deterministic Red-Flag Escalation System
A hardcoded lookup matrix intercepts extracted values for critical, life-threatening biomarker anomalies:

| Biomarker | Critical Threshold | Action |
| :--- | :--- | :--- |
| **Potassium ($K^+$)** | $< 2.8\text{ mEq/L}$ or $> 6.2\text{ mEq/L}$ | Immediate high-priority red banner: *"Critical Potassium Level: Requires urgent emergency medical evaluation."* |
| **Platelet Count** | $< 20,000/\mu\text{L}$ | Urgent red banner: *"Severely Low Platelets: High risk of bleeding. Seek prompt medical care."* |
| **Blood Glucose (Fasting)** | $> 350\text{ mg/dL}$ or $< 50\text{ mg/dL}$ | Urgent red banner: *"Severely Out-of-Range Glucose: Contact your physician immediately."* |

## 4. REST API Specification

### `POST /api/v1/ocr/extract`
* **Request:** `Multipart/form-data` with `file: UploadFile`, `language: string`, `consent: boolean`.
* **Response (200 OK):**
```json
{
  "session_id": "ephemeral-uuid-v4",
  "document_type": "LAB_REPORT",
  "extracted_items": [
    {
      "id": 1,
      "raw_text": "Hemoglobin 9.2 g/dL 12.0-15.0",
      "name": "Hemoglobin",
      "value": "9.2",
      "unit": "g/dL",
      "reference_range": "12.0 - 15.0",
      "confidence": 0.94,
      "bbox": [120, 340, 480, 42]
    }
  ]
}
```

### `POST /api/v1/explain`
* **Request:** `Application/json`
```json
{
  "session_id": "ephemeral-uuid-v4",
  "language": "hi",
  "reading_depth": "standard",
  "confirmed_items": [
    {
      "name": "Hemoglobin",
      "value": "9.2",
      "unit": "g/dL",
      "reference_range": "12.0 - 15.0"
    }
  ]
}
```
* **Response (200 OK):**
Returns structured explanations, deterministic status tags, red-flag escalation triggers, and 3–5 physician questions in the requested language.


## 6. Verification & Test Plan

1. **Adversarial Safety Test Suite:** Execute 100 adversarial prompts designed to coax the LLM into diagnosing diseases, recommending dosages, or evaluating unprinted ranges; verify 100% adherence to safety guardrails.
2. **OCR Benchmarking:** Test against scanned and photographed lab reports across major diagnostic chains (Dr. Lal PathLabs, SRL/Agilus, Metropolis, Anand Diagnostic).
3. **Multilingual Script Testing:** Automated visual regression testing for Hindi and Kannada font rendering in both responsive web views and generated PDF downloads.
